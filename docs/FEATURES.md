# Features

- Dashboard counts from IndexedDB, actual recent projects/activity and guided empty states.
- Project create/edit/delete, configuration duplication, search, sorting and ZIP export. Project deletion transactionally cascades associated evidence and records.
- Multiple image selection and drag/drop, PNG/JPEG/WebP decoding and size validation, original dimensions, naming, viewport assignment, download, gallery and image dialog.
- Persistent workspace selection, default/custom viewports, rotation, pan, zoom, fit, actual size, fullscreen and keyboard zoom shortcuts.
- Original-coordinate rectangle, pin, text and highlight annotations. SVG overlays retain alignment; coordinate forms allow keyboard creation, editing and deletion.
- Side-by-side shared zoom/optional synchronized scrolling, keyboard-accessible before/after slider and background-worker pixel difference visualization. Saved threshold, alignment and session parameters.
- Issues with categories, severities, statuses, screenshot/annotation links, reproduction steps and suggested fixes. Search/filter/sort, edit, resolve/reopen and deletion.
- Manual audit runs with status, viewport, URL and structured findings. Severity, screenshot evidence, suggestions and limitations persist. Edit/delete audits and findings.
- Filtered reports with issue distributions, audit summaries, corrective actions, comparison metadata and image evidence. JSON metadata, formula-escaped CSV and browser print-to-PDF.
- Full ZIP backups with original image binaries, version/schema validation, ID remapping, reference checks and atomic copy import. Destructive reset requires confirmation.
- Eight built-in viewports, custom preset CRUD, persistent theme/display/threshold/annotation/report/notification preferences and browser storage usage estimates.
- Responsive sidebar/drawer, focus-managed dialogs, system/light/dark themes, reduced motion, visible focus, feedback and error handling.

Automated target audits and runner connectivity are explicitly unavailable. No sample records are inserted silently.
