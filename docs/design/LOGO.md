# Responsive Studio logo

The mark combines a desktop/browser frame with a smaller mobile frame. Shared geometry represents testing one interface across screen sizes; the mint square suggests a completed check. Indigo `#4354ED` matches the application's primary accent, with mint `#2ED8A4` for the small detail.

- `public/brand/responsive-studio-mark.svg`: clean, editable production vector mark used in the sidebar. Native HTML provides the existing Responsive Studio wordmark.
- `public/brand/favicon.svg`: browser icon with a lighter indigo variant for dark browser chrome.
- `public/brand/favicon-32.png` and `public/brand/apple-touch-icon.png`: small raster exports rendered from the production SVG in Chromium.
- `public/brand/responsive-studio-mark.png`: original transparent PNG generated with the built-in Image Gen tool, preserved as a downloadable concept asset.

Keep the mark's proportions, transparent padding and mint detail. Avoid stretching, extra shadows or gradients. Sidebar integration retains an accessible dashboard link even when the sidebar is collapsed. The SVG is a simplified code-native rendering of the generated concept, rather than an automated vector export.

Verified: production build and lint; dashboard browser capture; image decoding and favicon response; light-mode default with dark OS preference; dark and collapsed sidebar rendering. Sidebar captures were visually inspected.

## Generation prompt

Use case: logo-brand. Asset type: final standalone transparent PNG brand mark for a professional developer application named Responsive Studio, which tests responsive website interfaces across desktop, tablet and mobile sizes. Create one distinctive extremely clean flat vector-style geometric logo mark, icon only, no lettering. Design: a bold indigo rounded desktop/browser outline with a second smaller vertical phone frame cut through or nested into its lower-right corner, forming a clever interlocking RS-like geometric monogram through negative space. A small mint square or short mint edge can subtly represent a successful layout check, but keep the logo almost entirely vivid indigo #4354ED. Strong recognizable silhouette and carefully balanced negative space, thick consistent geometric strokes, precise slightly rounded corners, no tiny details. It must read clearly as a favicon at 24px and as a sidebar brand icon on white and navy #101521. Square composition, centered mark fills roughly 88% of canvas with modest even transparent padding. Fully transparent background. No text, no words, no mockups, no presentation board, no shadows, no gradients, no glow, no 3D, no watermark. Deliver one polished original vector-like icon on transparency.
