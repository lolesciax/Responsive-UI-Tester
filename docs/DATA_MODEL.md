# Data model (version 1)

All records use UUID string IDs and millisecond timestamps. Projects own screenshots, comparisons, issues, audits and activity. Screenshots contain original image Blobs, decoded dimensions, MIME type, size and assigned viewport. Annotations belong to screenshots and store original-image pixel coordinates. Issues have category, severity, status, reproduction steps, suggestion and optional screenshot/annotation evidence. Comparisons reference two screenshots in the same project and retain mode, threshold and alignment. Audit runs own structured findings; manual runs explicitly retain their source. Presets include dimensions, orientation, device pixel ratio and category. Settings are separate from business data.

Dexie schema version 1 indexes foreign keys and dates. All related deletions and restores are transactional. Project duplication copies project configuration only to avoid duplicated evidence. Archive import remaps every ID and reference into a new copy, leaving existing records untouched. Full reset requires confirmation. Backup ZIPs contain all image bytes, and untrusted imports are schema-validated with size and reference limits.
