# Known limitations

- Optional Phase 5 local Playwright runner is not implemented. No automation server, automated target capture or arbitrary-site DOM inspection. E2E tests verify this app using controlled local image fixtures.
- Targets may block iframe embedding. Cross-origin DOM cannot be inspected and refusal cannot be detected reliably. Preview isolation blocks site storage by default; the explicit “Allow site storage” checkbox grants origin/storage privileges only for a trusted external origin during the current workspace visit. It is unavailable for Studio's own origin to avoid combining same-origin access with scripts there. Test local sites on a different port, or open them in a new tab. Top navigation and popups remain sandboxed. Browser privacy rules may still deny storage, and target CSP/X-Frame-Options still apply. Only enable this mode for sites you trust, including their redirects.
- If localStorage access is denied for Studio itself, UI preferences fall back to memory for the session. Project persistence still requires IndexedDB. An opaque-origin host iframe may deny both: open Studio directly in a browser tab rather than expecting a sandboxed embed to save projects.
- Manual observations and pixel differences do not establish responsive correctness or complete accessibility. Intentional changes and rendering variance can appear as differences.
- Difference mode composites transparency onto white and applies maximum-channel thresholds. No perceptual anti-aliasing classifier or automatic registration. Unequal dimensions retain explicit top-left/center alignment with white padding. The difference canvas is capped at 16 megapixels; uploads at 40 megapixels, 20,000px per edge and 20 MB per file.
- Pins/text annotations appear as numbered SVG markers, with full text in the inspector/editor. Rectangle drawing/resizing by drag and annotation undo/redo are not implemented; the coordinate form provides keyboard editing.
- Comparison zoom is shared. Saved sessions retain parameters rather than computed difference image Blobs.
- JSON reports include image metadata, not binary assets. ZIP backups include image files. Print reports show original screenshot evidence and comparison parameters, rather than interactive sliders or generated pixel-difference output. PDF uses the browser print dialog.
- Copy import preserves current UI preferences. Imported project records and custom presets are restored with new IDs; existing projects are not overwritten. Archives are capped at 250 MB compressed, 300 MB expanded and 25 MB per entry, with record-count limits. ZIP export uses no compression; large archive preparation still runs on the main thread.
- Browser storage can be evicted or removed and is scoped to profile/origin. No service worker, offline app cache or cross-device synchronization. Once loaded, local operations do not require a network service.
- Live queries load metadata and image Blobs in memory. Very large collections may need pagination and thumbnails. The UI shows the latest 100 activity events; backups include all events.
- Chromium is the automated test browser. Firefox/Safari, manual screen-reader testing and formal WCAG certification remain unverified. Axe scans do not prove complete conformance.
